# Identity & AI-Readiness Health Check (prototype)

Quick prototype showing how identity and data quality can be measured and improved with ML as a foundation for AI-driven marketing.
All data is synthetic. Built as a product-thinking demo, not a replica of any company's product.

## Run
```
pip install -r requirements.txt
streamlit run app.py
```
Optional: set `ANTHROPIC_API_KEY` (or paste a key in the "AI insights" tab) for a Claude-written brief. Without it, a template summary is used.

## What it does
1. **Synthetic data** (`data_gen.py`): ~3k messy records across 4 sources with nicknames, typos, missing fields, formatting differences, moves, and 4 planted data-quality incidents.
2. **ML identity matching** (`identity_ai.py`): blocking, fuzzy-match features, gradient-boosted classifier, evaluated on held-out people vs a rules-only baseline.
3. **Anomaly detection**: Isolation Forest over source/batch quality metrics, with the top driver named.
4. **AI-readiness score**: transparent weighted formula (identity coverage, consent, freshness, attribute depth).
5. **Insights**: optional LLM narrative constrained to the computed numbers.

## Caveat
Results come from synthetic data whose noise is generated by this repo; they illustrate the approach, not real-world performance.
